# v1.2 milestone

These instructions target `@luseefor/synthex-cli@1.2+` and `synthex-ui@2+`.

This note records the source checkpoint after [PR133](https://github.com/Luseefor/synthex-ui/pull/133).
Publication requires the versioned CI and npm checks in [the release procedure](../releasing.md).

## Milestone vs npm versions

Milestone `v1.2` is the release train name. The npm versions are:

| Milestone | Package | Version |
|---|---|---|
| v1.2 | `synthex-ui` | `2.0.0` |
| v1.2 | `@luseefor/synthex-cli` | `1.2.0` |
| v1.2 | `@luseefor/synthex-core` | `1.2.0` |
| v1.2 | `@luseefor/synthex-react-web` | `1.2.0` |

`synthex-ui` is major because of the native Carousel type break below; the
other packages receive minor version bumps for their accumulated changes.

## Included capabilities

- Framework onboarding: `create --template vite|next|expo` starters and
  `setup` for existing Vite / Next App Router / Expo SDK 58 apps
  (`synthex-ui.json` + CSS entry + provider wrapper, idempotent,
  never overwrites or edits build config). See [frameworks](../frameworks.md).
- Lean `add`: with `synthex-ui.json`, copies the app-platform files
  (web for Vite/Next, native for Expo) and prunes only `_shared` to the
  relative import closure; without config, keeps the legacy both-platform
  install. Reports `dependencies` + `installCommand`, never auto-installs.
  See [registry](../registry.md).
- Safe updates: read-only `diff` preview and `update` three-way merge that
  preserves independent local edits, stops all applies on any conflict,
  backs up successful runs under `.synthex/backups/<uuid>`, saves
  `base`/`local`/`incoming` sidecars under `.synthex/conflicts/<uuid>` only
  on a real conflicting run, and advances `.synthex/components.json` via
  `--resolved`. See [updating components](../updating-components.md).
- Native families: OTP focus/paste/backspace ([native otp](../native-otp.md)), Slider
  dragging/range/RTL ([native slider](../native-slider.md)), Resizable dragging
  ([native resizable](../native-resizable.md)), Sheet/Drawer modal contracts
  ([native sheet drawer](../native-sheet-drawer.md)), anchored Select/DropdownMenu/Popover/
  Combobox modals, and ContextMenu/HoverCard/Tooltip/NavigationMenu anchored
  modals with inline Command ([native remaining overlays](../native-remaining-overlays.md)).
- Web library repair (PR133): Overview dashboard layout rework and
  chart/combobox/command/OTP/toast/icon styling fixes.

## Migration

- Radix / TanStack churn: see [migration](../migration.md) (ToastAction `altText`,
  Menubar `value`, Select trigger, Tabs, DataTable, Dialog/Sheet/Drawer)
  and `node scripts/migrate-shadcn.mjs --dry-run <dir>`.
- Native Carousel breaking type change: see [native carousel](../native-carousel.md).
  `CarouselApi`, `CarouselOptions`, and `CarouselPlugin` under the native
  condition are native aliases (`NativeCarouselApi`:
  `scrollTo`/`scrollNext`/`scrollPrev`/`selectedScrollSnap`/
  `scrollSnapList`/`canScrollNext`/`canScrollPrev`/`on`/`off`), not the
  Embla engine. Migrate native consumers to `NativeCarouselApi`;
  `loop: true`, non-empty `plugins`, and unknown `opts` keys are rejected.
  Web Carousel remains on Embla. This break is recorded in a major-version
  changeset, hence `synthex-ui@2`.
