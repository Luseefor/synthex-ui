## Methodology

- `scripts/dep-map.mjs` walks every non-test source file under `packages/ui/src/<component>/`,
  collects `from "…"` / side-effect / dynamic `import("…")` specifiers,
  resolves relative imports to their target files (including into `_shared`, `hooks`, `icons`, and sibling components),
  and accumulates only specifiers present in `packages/ui/package.json#dependencies`.
- Test files (`*.test.*`, `*.spec.*`, `__tests__`), `node:` builtins, and peer deps are ignored.
- Versions in the install commands are pinned from `dependencies` at generation time.
